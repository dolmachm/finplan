# ФИНКОН — продуктовая документация

Документ для менеджеров и заказчиков: возможности, роли, API на уровне назначения. Без исходного кода.

Связанный документ: [DEVELOPER.md](./DEVELOPER.md) (архитектура и детали для разработки).

---

## 1. Продукт

**ФИНКОН (FinPlan)** — веб-сервис персонального финансового планирования.

Пользователь вводит своё финансовое положение (счета, долги, доходы, расходы, цели) и получает:

- сводку и оценку финансового здоровья;
- помесячный прогноз капитала;
- прогноз риска (множество рыночных сценариев);
- сравнение «что если…» через сценарии;
- детальный инвестиционный план;
- PDF-отчёт и импорт CSV.

**Позиционирование:** информационный / справочный сервис. Результаты **не** являются индивидуальной инвестиционной рекомендацией. Дисклеймер показывается в интерфейсе и в PDF.

**Валюта по умолчанию:** рубли (₽).

## 2. Аудитория и ценность

| Кому | Зачем |
|------|--------|
| Частный пользователь | Собрать «точку 0», понять профицит, цели и горизонт, оценить шансы достижения целей |
| Менеджер продукта | Каталог функций, границы продукта, роли |
| Поддержка | FAQ-логика: с чего начать, чем План отличается от Инвест-плана |

**Ценность:** один кабинет вместо разрозненных таблиц — баланс, поток, цели, риск и сценарии в связанной модели.

## 3. Структура интерфейса

### Публичные страницы

- Лендинг — описание продукта, регистрация / вход
- FAQ и «Как считаем» — объяснения без входа в кабинет

### Авторизация пользователя

- Регистрация и вход по email/паролю
- После входа — личный кабинет `/dashboard`

### Кабинет (4 вкладки)

| Вкладка | Подразделы | Смысл |
|---------|------------|--------|
| **Главная** | — | Скор, сводка, прогресс заполнения, инсайты |
| **Данные** | Баланс → Поток → Цели | Ввод и правка исходных данных |
| **План** | Обзор → Прогноз риска → Инвест-план → Сценарии | Расчёты и «что если» |
| **Экспорт** | Отчёт PDF → CSV | Выгрузка и импорт |

### Админ-панель

Отдельный вход (не тот же, что у пользователя кабинета). Управление пользователями, их финансовыми данными, журналами и очередью симуляций.

## 4. Возможности по модулям

### 4.1. Главная

- **Финансовый скор (0–100)** с градацией и блоками: благосостояние, бюджет, планирование, инвестиции
- **Сводка:** активы, пассивы, чистые активы, доход/расход в месяц, «можно откладывать»
- **Онбординг по шагам:** 1) точка 0 (баланс) → 2) денежный поток → 3) цели
- **Конверты бюджета** и **коридор накоплений** (сколько остаётся после лимитов категорий)
- **Инсайты и рекомендации** — что заполнить или улучшить дальше

Первые цифры на Главной подгружаются приоритетно; детальные блоки ниже по прокрутке.

### 4.2. Данные — Баланс («точка 0»)

- Активы (счета, брокер, недвижимость и др.) и пассивы (кредиты, ипотека)
- Чистые активы = активы − пассивы
- Демо-портфель для быстрого старта
- Редактор портфеля по классам активов, калькулятор **ребаланса**
- Калькулятор кредита и стратегии погашения (**лавина** / **снежный ком**)

### 4.3. Данные — Поток

- Доходы и расходы с периодичностью
- Профицит (что остаётся в месяц)
- **Конверты:** категории расходов с месячными лимитами, контроль перерасхода

### 4.4. Данные — Цели

- Цели: сумма, срок или этапы, приоритет, стратегия взносов
- Варианты достижения: накопления / кредит / гибрид
- **Макропараметры:** инфляция, НДФЛ, горизонт плана
- **История изменений** ключевых сущностей

### 4.5. План — Обзор

- Помесячный детерминированный прогноз капитала и денежного потока
- Рекомендуемый ежемесячный взнос
- Выбор активного сценария для пересчёта

### 4.6. План — Прогноз риска (Monte Carlo)

- Тысячи случайных траекторий рынка
- Вероятность достижения целей, медиана, осторожный и оптимистичный исходы
- Запуск асинхронно; есть дневная квота расчётов на пользователя

### 4.7. План — Инвест-план

- Годовой калькулятор: взносы, несколько вариантов, доходность и риск
- Сверка взносов с профицитом бюджета
- Отдельный пересчёт риска по запросу (не на каждое открытие вкладки)

### 4.8. План — Сценарии

- Правила **если → то → иначе** (в т.ч. вложенные)
- Шаблоны: кризис, потеря работы, продажа актива, рыночный шок и др.
- Проверка правил (например, предупреждение о неликвидности)
- Активация сценария и **сравнение** нескольких сценариев на графике

### 4.9. Экспорт

- **PDF:** настраиваемые блоки (обложка, резюме, баланс, поток, цели, допущения, прогноз, инсайты, рекомендации), правки текстов, дисклеймер
- **CSV:** импорт активов / доходов / расходов; отчёт по созданным и ошибочным строкам

### 4.10. PWA

- Установка на устройство (standalone)
- Офлайн: можно смотреть ранее загруженный интерфейс
- **Сохранение изменений только при наличии сети**

## 5. Роли

| Роль | Возможности |
|------|-------------|
| **Пользователь** | Свой кабинет: данные, план, экспорт. Данные других пользователей недоступны |
| **CONSULTANT** | Есть в модели пользователя; отдельного кабинета консультанта в продукте пока нет |
| **Админ-панель** | Отдельные учётные данные окружения. Список пользователей, статусы аккаунта, баланс, правка финансов пользователя, журналы, очередь Monte Carlo |

Админ **не** входит в пользовательский кабинет тем же логином, что NextAuth пользователя: это отдельная сессия.

## 6. Обзор API (назначение)

Все пользовательские операции с финансами требуют входа в аккаунт. Админские — отдельной админ-сессии.

### 6.1. Доступ и регистрация

| Метод | Путь | Назначение |
|-------|------|------------|
| — | `/api/auth/...` | Вход / сессия пользователя |
| POST | `/api/auth/register` | Регистрация |

### 6.2. Сводка и полный набор данных

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/api/finance/summary` | Итоговые цифры и скор для Главной (без полных списков) |
| GET | `/api/finance/snapshot` | Полные сущности для вкладок Данные / План |

### 6.3. Сущности финансов

Для каждой группы — список/создание и изменение/удаление по идентификатору:

- активы, пассивы, доходы, расходы, цели, категории бюджета
- макропараметры прогноза (`/api/macro`)

### 6.4. Сценарии и план

| Метод | Путь | Назначение |
|-------|------|------------|
| GET/POST | `/api/scenarios` | Список / создание |
| GET/PATCH | `/api/scenarios/{id}` | Чтение / правила и параметры |
| POST | `/api/scenarios/{id}/activate` | Сделать сценарий активным |
| POST | `/api/scenarios/{id}/validate-rules` | Проверить правила |
| GET | `/api/plan/projection` | Детерминированный прогноз |
| GET | `/api/plan/compare` | Сравнение сценариев |
| GET/PUT | `/api/iplan` | Инвест-план (тяжёлый риск — по отдельному запросу) |
| GET/POST | `/api/simulations` | Список / запуск Monte Carlo |
| GET | `/api/simulations/{id}` | Статус и результат расчёта |

### 6.5. Импорт, экспорт, история

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | `/api/import/csv` | Импорт CSV |
| GET/POST | `/api/export/pdf` | PDF-отчёт |
| GET | `/api/history` | История изменений пользователя |

### 6.6. Админ

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | `/api/admin/auth/login` | Вход в админку |
| POST | `/api/admin/auth/logout` | Выход |
| GET | `/api/admin/users` | Список пользователей |
| GET/PATCH/POST | `/api/admin/users/{id}` | Карточка, правка, действия с балансом/статусом |
| GET/PATCH/DELETE | `/api/admin/users/{id}/finance` | Финансы пользователя |
| GET | `/api/admin/users/{id}/history` | История пользователя |
| GET | `/api/admin/jobs` | Очередь симуляций |
| GET | `/api/admin/logs` | Журнал действий админа |

## 7. Что не входит в продукт

- Не брокер и не исполнение сделок
- Нет живых котировок и «рыночного совета» сверх введённых допущений пользователя
- Нет офлайн-сохранения изменений
- Нет полноценного кабинета консультанта (shared read-only планы — в бэклоге)
- Не налоговая декларация и не юридическая консультация

## 8. Эксплуатация (высокий уровень)

Для работы сервиса нужны:

- хранилище данных (Redis);
- секрет подписи сессий пользователя;
- в production — отдельные логин и пароль админ-панели;
- публичный URL приложения для корректной авторизации.

Детали установки и переменных окружения — в [DEVELOPER.md](./DEVELOPER.md) и корневом README.
